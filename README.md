# 🛍️ SmartSeg - Customer Segmentation & Personalized Offer System

**Major Internship Project** | Retail Analytics Dashboard

---

## 📋 Project Overview

SmartSeg is an intelligent **Customer Segmentation and Personalized Marketing Platform** built to help mall owners and retail businesses better understand their customers and increase sales through data-driven decisions.

The system analyzes customer purchase behavior using Machine Learning and provides:
- Customer segmentation
- Personalized offers
- Loyalty program
- Business insights
- AI-powered chat assistant

---

## ✨ Key Features

- **Customer Segmentation** using K-Means Clustering (5 segments)
- **Personalized Offer Engine** with multiple offers per segment
- **Gamified Loyalty Program** with Bronze, Silver & Gold tiers
- **Interactive Business Insights** with filters
- **Groq AI Chat Assistant** for natural language queries
- **Dataset Explorer** with search and SQL query support
- **MySQL Support** (Local + Railway Cloud)
- **Modern Dark Theme UI**

---

## 🛠️ Technologies Used

- **Frontend**: Streamlit
- **Data Processing**: Pandas, NumPy
- **Machine Learning**: Scikit-learn (K-Means)
- **Visualization**: Plotly Express
- **AI**: Groq (llama-3.3-70b-versatile)
- **Database**: MySQL (Railway Cloud + Local)
- **Deployment**: Railway
